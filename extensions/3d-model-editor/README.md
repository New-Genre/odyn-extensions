# 3d model editor

An Odyn extension.

```bash
bun install
bun run dev      # rebuilds on every save; Odyn reloads it
bun run publish  # sends it to the Marketplace for review
```

In Odyn, open Marketplace → Extensions → Install from folder and pick this folder.

Optional: add up to 5 pictures to the Marketplace page by listing them in the
`"odyn"` section of package.json, e.g. `"screenshots": ["screenshots/1.png"]`
(.png, .jpg, .jpeg or .webp, at most 1 MB each).

Docs: https://www.odyn.build/docs/extensions
